# inventory-management-system-python

---Gestor de Inventario en Python---

---Descripción---

Desarrollé una aplicación de consola en Python para la administración de inventarios, permitiendo registrar, consultar y filtrar productos de manera sencilla. El sistema facilita la gestión de información relevante como nombre, precio, categoría y existencia de cada producto.

Durante el desarrollo apliqué conceptos fundamentales de programación como el uso de listas y diccionarios para el almacenamiento de datos, funciones para la organización del código y validaciones para garantizar la integridad de la información ingresada por el usuario.

---Funcionalidades---

* Agregar nuevos productos al inventario.
* Mostrar todos los productos registrados.
* Buscar productos por nombre.
* Filtrar productos por categoría.
* Filtrar productos por rango de precio.
* Validación de datos ingresados por el usuario.
* Menú interactivo en consola.

---Tecnologías Utilizadas---

* Python 3
* Listas y diccionarios
* Funciones y estructuras de control
* Manejo de excepciones para validación de datos

---Habilidades Demostradas---

* Programación estructurada.
* Manipulación y gestión de datos.
* Uso de estructuras de datos (listas y diccionarios).
* Implementación de filtros y búsquedas.
* Validación de entradas del usuario.
* Organización y modularización de código.
* Desarrollo de aplicaciones de consola.

## Objetivo del Proyecto

Este proyecto fue desarrollado como práctica para fortalecer mis conocimientos en Python, aplicando estructuras de datos, lógica de programación y técnicas de validación utilizadas comúnmente en sistemas de gestión e inventarios.
